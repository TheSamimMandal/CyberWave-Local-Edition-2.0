**Router Target:** TP-Link Archer C6 US V3.2 (`tplink,archer-c6-v3`)  
**Firmware Target:** OpenWrt 25.12.6 · `ramips/mt7621` · MIPS architecture · `apk` package manager

## 1. Overview & Architecture

CyberWave provides a true one-click, autonomous installation and provisioning system for the TP-Link Archer C6 V3.2 running OpenWrt 25.12.6.

### Key Capabilities:
- **Zero Multiple Package Uploads:** A single 13 KB self-contained archive (`cyberwave-bundle.tar.gz`) bundles all agent scripts, guest wireless automation, openNDS captive portal templates, procd init definitions, and rollback utilities.
- **Single Installation Entry Point:** One unified script (`cyberwave-oneclick-installer.sh`) handles all 10 stages sequentially with real-time cloud progress reporting.
- **Automatic Dual-Band Guest Wi-Fi:** Detects 2.4 GHz and 5 GHz hardware radios, generates dedicated guest interfaces (`guest_2g`, `guest_5g`), creates an isolated `192.168.9.1/24` network, and configures DHCP pool (192.168.9.100 - 192.168.9.200).
- **Protected Primary LAN:** The openNDS captive portal is strictly bound to `gatewayinterface guest`. Trusted administrator LAN clients are **never** redirected or intercepted.
- **Firewall Isolation:** Zone `guest` forwards exclusively to `wan`. Forwarding to `lan` is blocked by default, with only DHCP (UDP 67) and DNS (UDP/TCP 53) allowed to the router.
- **Anti-Bricking & Flash Protection:** Enforces minimum 256 KB free overlay storage check, tests syntax (`sh -n`), verifies SHA-256 component checksums against `install-manifest.json`, and saves pre-install UCI backups before touching configuration.
- **Non-Destructive Rollback & Uninstall:** One command restores the pristine pre-installation state without factory resetting the router.

## 3. Installation Methods

### Method A: Web Dashboard One-Click (Recommended)
1. Open the CyberWave Admin Dashboard: `http://localhost:3000/admin.html`
2. Log in using your admin credentials.
3. In the **Settings / Remote OpenWrt Router Bridge** tab:
   - Click **Regenerate Pairing Token** (if pairing for the first time).
   - Click the prominent gradient button:  
     **`INSTALL COMPLETE CYBERWAVE SETUP`**
4. The dashboard will dispatch the complete 10-stage setup to the router. You can monitor progress on the visual 10-stage checklist, progress bar, and real-time live terminal log.

### Method B: Single-Line SSH Terminal Command
1. Connect to the Archer C6 via SSH from your computer or phone:
   ```sh
   ssh root@192.168.1.1
   ```
2. Run the one-line bootstrap command generated by CyberWave Admin:
   ```sh
   uclient-fetch -q --timeout=30 -O - "http://localhost:3000/api/router?action=oneclick_script&ticket=YOUR_TICKET" | sh
   ```
3. The installer runs autonomously, verifying checksums, creating the backup, provisioning guest Wi-Fi, configuring openNDS, and starting the procd daemon.

### Method C: Offline Bundle Installation
For air-gapped environments without direct package repository access:
1. Download `cyberwave-oneclick-installer.sh` and `cyberwave-bundle.tar.gz`.
2. Transfer both files to `/tmp` on the router via SCP:
   ```sh
   scp cyberwave-oneclick-installer.sh cyberwave-bundle.tar.gz root@192.168.1.1:/tmp/
   ```
3. Run the installer in offline mode:
   ```sh
   sh /tmp/cyberwave-oneclick-installer.sh "http://192.168.1.100:3000" "cw-c6-local" "local-token" --offline --bundle=/tmp/cyberwave-bundle.tar.gz
   ```

## 4. The 10 Installation Stages

```text
[Stage 1: Pre-install Checks] -> Hardware, Release 25.12.6, 256KB Flash check
             |
[Stage 2: Backup]             -> /etc/cyberwave/backups/backup-<epoch>.tar.gz
             |
[Stage 3: Dependencies]       -> Installs missing jsonfilter via apk
             |
[Stage 4: Bundle Validation]  -> Extracts tar.gz and verifies SHA-256 checksums
             |
[Stage 5: Agent Installation] -> /usr/bin/cyberwave-agent.sh & procd service
             |
[Stage 6: Guest Wi-Fi Setup]  -> Detects 2.4G & 5G radios, creates guest_2g & guest_5g
             |
[Stage 7: Firewall Zone]      -> Guest -> WAN allowed, Guest -> LAN blocked
             |
[Stage 8: openNDS Captive]    -> Binds openNDS to guest only; sets FAS & voucher auth
             |
[Stage 9: Service Activation] -> Enables procd daemon, reloads wireless & firewall
             |
[Stage 10: Health Checks]     -> Process audit, ping verify, 100% completion report
```

1. **Stage 1 — Pre-installation checks (10%):** Validates root privileges, board compatibility (`tplink,archer-c6-v3`), firmware target (`25.12.6`), free storage on `/overlay` (≥ 256 KB), and available RAM.
2. **Stage 2 — Configuration backup (20%):** Archives `/etc/config/wireless`, `network`, `firewall`, `dhcp`, and `opennds` into `/etc/cyberwave/backups/backup-<timestamp>.tar.gz` and writes `/etc/cyberwave/backups/restore-pre-cyberwave.sh`.
3. **Stage 3 — Dependency installation (30%):** Detects package manager (`apk` in 25.x). Checks if `jsonfilter` or `ca-certificates` are missing and installs only missing packages.
4. **Stage 4 — Bundle extraction & validation (40%):** Retrieves `cyberwave-bundle.tar.gz`, unpacks to `/tmp/cyberwave-bundle/`, and verifies SHA-256 checksum of every file against `install-manifest.json`.
5. **Stage 5 — CyberWave Agent installation (50%):** Deploys `/usr/bin/cyberwave-agent.sh` (0755), sets `/etc/cyberwave/agent.conf` (0600), registers `/etc/init.d/cyberwave-agent` with OpenWrt procd, and installs rollback/uninstall tools.
6. **Stage 6 — Guest Wi-Fi integration (65%):** Scans hardware radios for 2.4 GHz and 5 GHz bands. Deploys `guest_2g` and `guest_5g` interfaces with client isolation (`isolate=1`). Configures static IP `192.168.9.1/24` and guest DHCP pool. Primary Wi-Fi remains completely untouched.
7. **Stage 7 — Firewall isolation (75%):** Configures zone `guest` with forward to `wan` enabled, forward to `lan` blocked, and input rules allowing DHCP and DNS.
8. **Stage 8 — openNDS Captive Portal (85%):** Configures `/etc/config/opennds` with `gatewayinterface guest`. Captive portal operates exclusively on guest clients. Trusted LAN clients are never redirected.
9. **Stage 9 — Cloud Bridge pairing & service activation (90%):** Enables procd service, reloads network, firewall, and wireless subsystems, and triggers outbound pairing heartbeat.
10. **Stage 10 — Final health checks (100%):** Audits daemon execution (`ps | grep cyberwave-agent`), checks gateway ping response, verifies guest radio beacons, and reports completion to CyberWave Cloud.

## 5. Rollback & Uninstallation Procedures

### Emergency Configuration Rollback
If you need to instantly revert to the pre-installation network and wireless state:
```sh
sh /etc/cyberwave/backups/restore-pre-cyberwave.sh
```
Or click the **Rollback to Backup** button in the CyberWave Admin Dashboard.

### Clean Uninstallation
To completely remove all CyberWave services, guest interfaces, and captive portal hooks without resetting primary WAN, LAN, or main Wi-Fi:
```sh
sh /usr/bin/cyberwave-uninstall.sh
```
Or click the **Clean Uninstall** button in the CyberWave Admin Dashboard.

## 6. Security Considerations
- **No Inbound Ports:** The bridge uses outbound HTTPS polling only. No SSH, LuCI, or Telnet ports are exposed to the WAN.
- **Short-Lived Tickets:** Single-line installer tickets expire in 5 minutes and are single-use.
- **Allowlisted Execution:** Remote actions use structured parameters validated by `lib/router/safety.js`. Arbitrary remote shell injection is blocked.
- **Restricted File Permissions:** Secrets in `/etc/cyberwave/agent.conf` are locked with `chmod 0600`.
- **Integrity Verification:** Checksums of all bundle components are validated before execution.
